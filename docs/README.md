# Elasticsearch Docs

Elasticsearch 문서는 학습 문서, 규칙, 템플릿, 에이전트 프롬프트를 함께 관리합니다.

| 폴더 | 내용 |
|------|------|
| `core-concepts/` | 클러스터 아키텍처, 인덱스 설계, Query DSL |
| `operations/` | 인덱스/클러스터 관리, 스냅샷 복구 |
| `performance/` | 인덱싱/검색 성능, 리소스 튜닝 |
| `security/` | 인증, 인가, TLS |
| `observability/` | 모니터링, Slow Log |
| `rules/` | 문서 작성 및 운영 규칙 |
| `templates/` | 서비스 문서, 런북, 장애 보고서 템플릿 |
| `agents/` | Claude 에이전트 프롬프트 |

처음 읽을 문서는 `core-concepts/cluster-architecture.md`입니다.
