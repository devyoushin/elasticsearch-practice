# elasticsearch-practice 문서

이 디렉토리는 주제별 번호 체계로 문서를 정리합니다. 앞 번호는 학습과 운영 흐름을 나타내며, 90번대는 저장소 관리용 문서입니다.

## 문서 구조

- [01-core-concepts](./01-core-concepts/): Elasticsearch 핵심 개념 - 클러스터, 인덱스, Query DSL 기본 문서를 모읍니다.
- [02-operations](./02-operations/): 운영 - 클러스터, 인덱스, 스냅샷 운영 문서를 모읍니다.
- [03-performance](./03-performance/): 성능 최적화 - 색인, 검색, 리소스 튜닝 문서를 모읍니다.
- [04-observability](./04-observability/): 관측성과 모니터링 - 모니터링과 slow log 문서를 모읍니다.
- [05-security](./05-security/): 보안 - 인증, 인가, TLS 문서를 모읍니다.
- [90-standards](./90-standards/): 문서 작성 표준 - 저장소 문서 작성 규칙과 운영 기준을 관리합니다.
- [91-templates](./91-templates/): 문서 템플릿 - 반복해서 사용하는 문서 템플릿을 관리합니다.
- [99-agents](./99-agents/): AI 에이전트 가이드 - Elasticsearch 분석과 문서화에 활용할 에이전트 역할 정의를 관리합니다.
